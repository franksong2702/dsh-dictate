### English

`dsh-dictate v0.4.0-alpha.3` adds an optional local SenseVoice transcription path while keeping browser Web Speech as the default.

What is new:

- Start, stop, inspect, and test the plugin-managed SenseVoice service on `127.0.0.1:39081` from the plugin settings. Custom loopback endpoints remain externally managed.
- Keep local-mode audio on the same machine through a loopback-only endpoint.
- See clear recording, voice-detected, transcription, polishing, and completion feedback in the Composer.
- Preserve about 600 ms of ending audio after stopping to reduce clipped final words.
- Choose how to handle an unavailable local service: stay local, ask before using Web Speech, or allow pre-recording fallback.
- Never silently reroute audio that has already been recorded.

Existing users do not need to change anything: Web Speech remains the zero-setup default. The local mode is an experimental enhancement and requires a local FunASR/SenseVoice environment; the first model download is close to 1 GB.

The plugin still keeps text in the Composer for review by default. Model polishing and auto-send remain opt-in.

Requires DeepSeek Harness `0.1.0-rc.7` and Chrome or Edge.

Community project; not affiliated with or endorsed by DeepSeek or DeepSeek Harness.
